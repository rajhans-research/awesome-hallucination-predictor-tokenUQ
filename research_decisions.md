### Decision D02: Hardware-Aware Experimental Scoping
- **Date:** 2026-11-04
- **Decision:** Empirically audit local hardware before committing to an experimental design. Confirmed local system has an NVIDIA GeForce GTX 1050 with 4GB VRAM and an Intel CPU.
- **Reasoning:** 4GB VRAM cannot run 7B+ parameter LLMs directly in fp16/bf16. Attempting to generate 20 stochastic samples per prompt from a large local model would cause Out-Of-Memory (OOM) errors or stall for hours.
- **Source / Evidence:** `nvidia-smi` diagnostic execution output (Driver 572.47, CUDA 12.8, VRAM 4096 MiB).
- **Next Action:** Choose a canonical dataset with pre-generated generation and stochastic sample artifacts, while ensuring local model verification is runnable.

### Decision D03: Selection of Primary Dataset
- **Date:** 2026-11-04
- **Decision:** Select `potsawee/wiki_bio_gpt3_hallucination` hosted on Hugging Face Datasets.
- **Reasoning:** 
  1. Contains 238 entity biographies generated by GPT-3 (`text-davinci-003`).
  2. Features 1,908 human-annotated sentences categorized as `accurate`, `minor_inaccurate`, or `major_inaccurate`.
  3. Includes exact token-level log-probabilities for the primary generation.
  4. Includes 20 stochastic alternate generations per concept, making both single-pass token UQ and multi-pass sampling consistency directly comparable under an identical protocol.
  5. Fully open under MIT License.
- **Source / Evidence:** Manakul et al. (EMNLP 2023) [5]; Hugging Face repository `potsawee/wiki_bio_gpt3_hallucination`.
- **Next Action:** Verify loading and token alignment in Milestone M1.

### Decision D04: Selection of Primary Research Direction (Pareto Frontier)
- **Date:** 2026-11-04
- **Decision:** Adopt Pathway B (Controlled Comparative Study) investigating the Cost-Quality Pareto Frontier between single-pass token uncertainty methods and multi-pass sampling consistency methods.
- **Reasoning:**
  1. Section 7.4 of the author's review explicitly calls for a Pareto analysis between detection quality, latency, and model access.
  2. Single-pass methods cost $1\times$ inference; multi-pass methods cost $10\times\text{--}20\times$ inference plus semantic comparison.
  3. Characterizing the exact trade-off curve provides high-value empirical guidance to research and industry.
- **Source / Evidence:** `PAI_01_Rajhans.pdf`, Section 6.4, Section 7.4; `atr_final_assignment.pdf`, Section 3 (Pathway B).
- **Next Action:** Formulate Gate G1 Research Brief and present for user approval.

### Decision D05: Formulation of Deeper Analyses

### Decision D06: Exact Label Protocols & `text_offset` Alignment
- **Date:** 2026-11-12
- **Decision:** Implement all three canonical evaluation protocols from Manakul et al. (2023) (`nonfact`, `nonfact_star`, `factual`) plus `major_only`, and align sentence-to-token spans via API `text_offset` coordinates rather than naive string matching.
- **Reasoning:** Guarantees `1,908 / 1,908` exact sentence alignments even on multi-byte UTF-8 entity names (`Týr`, `Sirið`), eliminating alignment drops in the original notebook.
- **Source / Evidence:** `baseline_validation.md`; `results/logs/gate_g2_baseline_run.log`.
- **Next Action:** Present Gate G2 validation report to researcher before implementing the proposed `token_keyword` method and Pareto budget sweep.
